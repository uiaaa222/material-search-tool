# 内网素材剪贴板检索工具
## 项目背景
日常广告投放素材核对工作中，需要从Excel/WPS大量素材名称，在内网共享盘查找对应的视频文件。
人工逐个打开文件夹查找耗时久，WPS宏无法实现后台剪贴板监听，因此开发一款Windows轻量化自动化工具提升素材核对效率。

## 功能特性
1. 单行复制自动检索：复制单个素材名称，后台自动递归遍历内网UNC共享目录，弹窗展示匹配文件
2. 批量多行检索：支持复制多行素材列表，一键批量搜索，结果导出txt文档，可直接粘贴回表格核对
3. Windows系统托盘后台运行，无需保持黑窗口
4. 日志记录完整搜索历史，支持自定义搜索路径、过滤文件后缀、匹配规则
5. 兼容企业内网共享盘，增加网络访问异常捕获，规避网盘抖动丢失文件的问题

## 技术栈
Python / pywin32 / pystray / Windows API

## 迭代优化记录（项目踩坑与优化）
1. 初始版本过滤mp4素材文件，导致视频素材检索不到 → 修改后缀过滤配置
2. 早期仅支持单行搜索，复制多行只能读取第一行 → 新增独立批量搜索模式
3. 内网共享盘网络波动，部分子文件夹静默跳过扫描 → 增加异常捕获逻辑
4. 防止一次性大量关键词拖垮共享盘 → 限制批量最大行数，批量功能改为手动触发

## 使用教程
1. 安装Python，执行依赖命令
2. 修改clip_search.py中的SEARCH_ROOT为你的内网素材路径
3. 双击`启动搜索.bat`运行程序，右下角托盘待命
4. 单行复制自动搜索；多行复制通过托盘菜单执行批量搜索

## 项目价值
把原本几十分钟的人工素材核对工作缩短到几分钟，减少重复机械操作，提升投放素材复盘效率。
