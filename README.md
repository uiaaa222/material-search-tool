# 内网广告素材自动化工具集
## 项目背景
广告投放素材复盘工作：需要从WPS表格的大量素材名称，在内网UNC共享盘查找视频素材，并批量导出素材到本地文件夹。
WPS原生宏能力有限，因此开发两套Python工具，形成完整工作流，减少大量人工查找、复制的重复操作。

**工作链路：**
1. 剪贴板检索工具：复制WPS素材名称，在内网共享盘递归搜索，输出匹配文件完整路径列表
2. 批量复制工具：读取路径txt清单，批量把内网文件/文件夹复制到目标目录，自动处理同名冲突、进度展示、失败记录

## 🧩工具1：剪贴板检索工具 clip_search.py
### 功能特性
1. 单行复制自动检索：复制单个素材名称，后台自动递归遍历内网UNC共享目录，弹窗展示匹配文件
2. 批量多行检索：支持复制多行素材列表，一键批量搜索，结果导出txt文档，可直接粘贴回表格核对
3. Windows系统托盘后台运行，无需保持黑窗口
4. 日志记录完整搜索历史，支持自定义搜索路径、过滤文件后缀、匹配规则
5. 兼容企业内网共享盘，增加网络访问异常捕获，规避网盘抖动丢失文件的问题

### 技术栈
Python / pywin32 / pystray / Windows API

### 使用教程
1. 安装Python，执行依赖命令
2. 修改`clip_search.py`中的`SEARCH_ROOT`为你的内网素材路径
3. 双击`启动搜索.bat`运行程序，右下角托盘待命
4. 单行复制自动搜索；多行复制通过托盘菜单执行批量搜索，输出路径清单txt

## 🧩工具2：批量路径复制工具 copy_script.py
> 承接检索工具输出的路径文本，批量复制内网共享盘文件、文件夹到本地。
### 功能特性
1. 两种输入模式：读取txt路径清单 / 手动粘贴多行路径
2. 文件、文件夹均可复制；复制进度条可视化
3. **同名文件自动加序号，防止覆盖丢失文件**
4. 统计复制成功、失败、重命名数量，输出失败原因清单
5. 适配内网UNC网络共享路径，适合广告素材批量导出

### 使用教程
```bash
# 无需额外第三方依赖，python原生库即可运行
python copy_script.py
